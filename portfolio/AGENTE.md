
# Regras do projeto

- Criar um portfólio pessoal usando HTML, CSS e JavaScript puro.
- Não utilizar frameworks.
- Consultar referencias.md, identidade.md e funcionalidades.md antes de alterar o projeto.
- Manter o código organizado em index.html, style.css e script.js.
- Criar um design original, bonito e responsivo para celular e computador.
- Explicar as alterações realizadas.
- O site deve ter as seções Sobre mim, Projetos e Contato.
